# defineConfig

`bundoc.config.ts` exports a `BundocConfig`. The `defineConfig` helper
is identity-typed so you get autocomplete:

```ts title="bundoc.config.ts"
import { defineConfig } from "@clusterize/bundoc/config";

export default defineConfig({
  locales: ["en", "de"],
  defaultLocale: "en",
  contentDir: "./content",
  themeEntry: "./theme/index.tsx",
  basePath: "/",
  mdx: { highlighting: true },
});
```

## `locales`

```ts
locales: string[];
```

The set of available locales. bundoc treats them as opaque strings
(BCP-47 codes are conventional, but not enforced).

**Required.** Must contain at least one entry.

## `defaultLocale`

```ts
defaultLocale: string;
```

Which locale's URLs are served unprefixed. All other locales are
prefixed with `/<locale>`.

**Required.** Must be one of `locales`.

## `contentDir`

```ts
contentDir?: string;  // default: "./content"
```

Path (relative to the project root) where MDX content lives. The
file-system tree under this directory becomes your routes.

## `themeEntry`

```ts
themeEntry?: string;  // default: "./theme/index.tsx"
```

Path to your theme's default-exported component. The exported value
must be a React component bundoc can mount.

## `mdxComponentsEntry`

```ts
mdxComponentsEntry?: string;  // default: "./theme/mdx-components.tsx"
```

Path to a module that default-exports an MDX components map.
Optional — if the file doesn't exist, bundoc uses an empty map.

## `basePath`

```ts
basePath?: string;  // default: "/"
```

URL prefix the site is hosted under. Stripped on incoming requests
and re-prepended on outgoing hrefs. See
[Routing → basePath](/guides/routing#basepath).

## `titleTemplate`

```ts
titleTemplate?: string;  // default: undefined
```

Template applied to `document.title` on every navigation. The literal
`%s` is replaced with the current page's title (frontmatter `title`
when present, otherwise the route-derived label).

```ts
export default defineConfig({
  locales: ["en"],
  defaultLocale: "en",
  titleTemplate: "%s — bundoc",
});
```

A page whose title is `Installation` renders as
`Installation — bundoc` in the browser tab. When omitted, bundoc
leaves the bare title in place. Validation requires `%s` to appear at
least once.

## `mdx.highlighting`

```ts
mdx?: {
  highlighting?: boolean | { light?: string; dark?: string };
};
// default: off
```

Build-time syntax highlighting via Shiki. `true` enables the default
themes (`github-light` / `github-dark`); pass an object to pick
[any Shiki bundled theme](https://shiki.style/themes).

```ts
mdx: {
  highlighting: { light: "vitesse-light", dark: "vitesse-dark" },
}
```

When enabled, bundoc emits both themes via CSS variables; the
`.dark` class on `<html>` switches the active one. Zero runtime
bundle cost — the highlighter runs at build time.

## `pdf`

```ts
pdf?: {
  title?: string | Record<string, string>;  // default: "Documentation"
  fileName?: string;                        // default: "handbook"
  themeEntry?: string;                      // default: "./theme/pdf.tsx"
  format?: "A3" | "A4" | "A5" | "Letter" | "Legal"
         | { width: string; height: string };  // default: "A4"
  landscape?: boolean;                      // default: false
  margin?: { top?: string; right?: string; bottom?: string; left?: string };
  // default: { top: "22mm", right: "18mm", bottom: "20mm", left: "18mm" }
  cover?: boolean;                          // default: true
  toc?: boolean;                            // default: true
  filter?: (page: PdfablePage) => boolean;  // default: defaultPdfFilter
};
```

Settings for [`bundoc pdf`](/guides/pdf).

- `title` is passed to every PDF component and written into the PDF's
  metadata. Give a per-locale map to translate it.
- Lengths are CSS lengths (`"20mm"`, `"0.75in"`). The top and bottom
  margins hold `PdfHeader` and `PdfFooter`.
- `filter` receives `{ route, locale, title, frontmatter, fallback }`
  for every page in every locale, including fallback rows.
  `defaultPdfFilter` drops pages with `pdf: false` in their
  frontmatter. Extend it the same way as the search filter.

```ts
import { defaultPdfFilter, defineConfig } from "@clusterize/bundoc/config";

export default defineConfig({
  locales: ["en", "de"],
  defaultLocale: "en",
  pdf: {
    title: { en: "Handbook", de: "Handbuch" },
    filter: (p) => defaultPdfFilter(p) && !p.route.startsWith("/internal/"),
  },
});
```
