# CLI

```text
bundoc <command> [options]
```

All commands read `bundoc.config.ts` from the working directory.

## `bundoc dev`

Start the dev server with HMR.

```bash
bunx @clusterize/bundoc dev
bunx @clusterize/bundoc dev --port 4000 --host 0.0.0.0
```

| Flag | Default | Notes |
|------|---------|-------|
| `--port <n>` | `3000` | Listening port. |
| `--host <addr>` | `localhost` | Bind address. |

The dev server watches `content/` and `theme/`, recompiles single MDX
files on change, and rebuilds the manifest when files are added or
removed. Output goes to `.bundoc/cache/`.

## `bundoc build`

Build a static site to `dist/`.

```bash
bunx @clusterize/bundoc build
bunx @clusterize/bundoc build --out public
```

| Flag | Default | Notes |
|------|---------|-------|
| `--out <dir>` | `dist` | Output directory. |

Build artifacts include the SPA shell, code-split route chunks, your
CSS, and per-locale search indexes under
`<out>/_bundoc/search/<locale>.json`.

## `bundoc preview`

Serve a previously built `dist/` with SPA fallback.

```bash
bunx @clusterize/bundoc preview
bunx @clusterize/bundoc preview --port 4173
```

| Flag | Default | Notes |
|------|---------|-------|
| `--out <dir>` | `dist` | Directory to serve. |
| `--port <n>` | `4173` | Listening port. |
| `--host <addr>` | `localhost` | Bind address. |

Useful for verifying the static build before deploying.

## `bundoc pdf`

Render the [PDF handbook](/guides/pdf): one file per locale.

```bash
bunx @clusterize/bundoc pdf
bunx @clusterize/bundoc pdf --locale de
```

| Flag | Default | Notes |
|------|---------|-------|
| `--out <dir>` | `dist/_bundoc/pdf` | Output directory; files are `<pdf.fileName>.<locale>.pdf`. |
| `--locale <list>` | all locales | Comma-separated subset, e.g. `en,de`. |

Needs [Playwright](https://playwright.dev) and its Chromium
(`bun add -d playwright && bunx playwright install chromium`). The
command builds its own print bundle, so you don't need to run
`bundoc build` first. Run it *after* `build` if the PDFs should ship
with the site, because `build` wipes `dist/`. Set
`BUNDOC_PDF_DEBUG=1` to keep the raw content and header/footer renders
in `.bundoc/pdf-debug/`.

## `bundoc init`

Scaffold a new project.

```bash
bunx @clusterize/bundoc init my-docs
bunx @clusterize/bundoc init .       # current directory
```

| Positional | Default | Notes |
|------------|---------|-------|
| `<dir>` | `.` | Directory to scaffold into. |

Creates `bundoc.config.ts`, `bunfig.toml`, `content/`, and `theme/`.

## Global flags

```bash
bunx @clusterize/bundoc --help
bunx @clusterize/bundoc --version
```
